# SummarAIze — frontend

Next.js 16 (App Router) frontend for SummarAIze. See the [repo root README](../README.md)
for setup, architecture, and deployment — this package doesn't stand alone (it talks to the
backend in `../backend`).

Local dev: `npm install && npm run dev` (after copying `.env.local.example` to `.env.local`).
